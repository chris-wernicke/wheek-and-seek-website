5. Anonymous usage statistics

So that we can tell whether the game loads reliably and how we can improve it, the game sends anonymous usage data to our server (wheek-mp.denkgold.de) while you play. This covers which parts of the game are reached and how often certain game features are used (e.g. “game loaded”, “match started”, playing time) and how a match ended, namely who won and in which score range (e.g. “10 to 14 points”). Results are counted only as a rough group, never as an individual score and never linked to a person or device. In addition there is technical context such as game version, platform and device type (phone or computer – the game does not read this from your device: the server derives it from the browser identification that every request carries anyway, and discards that immediately).

Only aggregated totals are stored (e.g. per day and game version). There is no user or device identifier and no cookie, and nothing is stored on your device for this purpose. Individual players or devices cannot be told apart. Your IP address is transmitted for technical reasons. It is neither stored nor logged; only to prevent abuse it is immediately turned, irreversibly, into a short value using a random key that changes every minute, and that value stays in memory for one minute at most. The totals are deleted after 30 days at the latest.

If “Do Not Track” or “Global Privacy Control” is switched on in your browser, the game sends no usage data.

Legal basis: Art. 6(1)(f) GDPR (legitimate interest in improving the game and detecting technical problems). You can object at any time (Art. 21 GDPR): switch off “Anonymous statistics” in the settings of the start menu (gear, top right). It takes effect at once, nothing is sent after that; no email is needed. Because the totals cannot be linked to a person, individual entries can neither be looked up nor deleted (Art. 11 GDPR); that is not necessary either, as everything is deleted after 30 days at the latest.

6. Storage on your device
