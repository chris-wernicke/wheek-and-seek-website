Der Server fügt außerdem aus seiner eigenen Uhr eine grobe Tageszeit hinzu (ein Drei-Stunden-Block, UTC).

Gespeichert werden ausschließlich zusammengefasste Summen (z. B. je Tag und Spielversion). 5. Online mode (multiplayer)

Only when you start online mode does your browser connect to our game server. We then process:

  • IP address – technically required for the connection; kept in memory only while connected, never stored.
  • Platform display name – only if you are signed in on a game platform (e.g. CrazyGames): your username there is sent to your opponent in the same room and shown to them as your opponent’s name while you are in the room. Names containing links or special characters are not passed on. Without signing in, the name of your guinea pig (from a fixed list) is shown.
  • Guinea pig, level and emojis – so that your opponent can see you, the look of your guinea pig (e.g. breed, colours, accessory and a name from a fixed list), your level and, if you send one of four small pictures (emojis), its number are sent to your room. There is no text input and no chat.
  • Open arena – “Play” puts you into a room where up to 12 real players play together; free places are filled by computer guinea pigs. The browser of one player in the room (the “host”) calculates the field: the other players’ details (position, heading, hearts, snacks eaten) go through our server to that browser, which sends the result back to everybody in the room. If the host leaves, another player in the room takes over. Your name (your guinea pig’s name from a fixed list; only if you switch it on yourself in the settings, your platform name), the look of your guinea pig and your level are visible to everybody in the room while you are in it. So that the room is led by the device that can draw the field best, the devices also report their current frame rate and whether the window is visible; this is kept in memory only and is not stored. The server only passes this on and stores none of it; there are no accounts and no chat.
  • Room code and game actions – shared with your room in real time and discarded after the match. This includes position, heading, hearts, score and snacks eaten; there are no names, no accounts and no chat. The server only passes this on to the other players in the room and does not store it.
  • Anonymous operating statistics – number of concurrent players and rooms and server load, without IP addresses, names or other identifiers.

Legal basis: Art. 6(1)(b) GDPR (providing the online game you chose) and Art. 6(1)(f) GDPR (server security and stability). Participation is voluntary; online play is not possible without this data.

6. Anonymous usage statistics

So that we can tell whether the game loads reliably and how we can improve it, the game sends anonymous usage data to our server (wheek-mp.denkgold.de) while you play. This covers which parts of the game are reached and how often certain game features are used (e.g. “game loaded”, “match started”, playing time) and how a match ended, namely who won and in which score range (e.g. “10 to 14 points”). Results are counted only as a rough group, never as an individual score and never linked to a person or device. In addition there is technical context such as game version, platform and device type (phone or computer – the game does not read this from your device: the server derives it from the browser identification that every request carries anyway, and discards that immediately). This may also include rough information about game quality (e.g. the chosen graphics setting or the rough class of how smoothly the game ran) and about events in the game. The server also adds, from its own clock, a rough time of day (a three-hour block, UTC).

Only aggregated totals are stored (e.g. per day and game version). There is no user or device identifier and no cookie, and nothing is stored on your device for this purpose. Individual players or devices cannot be told apart. Your IP address is transmitted for technical reasons. It is neither stored nor logged; only to prevent abuse it is immediately turned, irreversibly, into a short value using a random key that changes every minute, and that value stays in memory for one minute at most. Within that one minute, requests from the same address can be told apart: until then the short value is a pseudonym, and afterwards it is useless. On the game server the totals and their backup copies are deleted after 30 days at the latest. To compare game versions, the operator also keeps a separate evaluation file of plain daily totals, likewise without any link to a person, on their own computer.

If “Do Not Track” or “Global Privacy Control” is switched on in your browser, the game sends no usage data.

Legal basis: Art. 6(1)(f) GDPR (legitimate interest in improving the game and detecting technical problems). You can object at any time (Art. 21 GDPR): switch off “Anonymous statistics” in the settings of the start menu (gear). It takes effect at once, nothing is sent after that, not even on your next visit (the game remembers your choice as a setting in your browser); no email is needed. Because the totals cannot be linked to a person, individual entries can neither be looked up nor deleted (Art. 11 GDPR); that is not necessary either, as they are not linked to any person and are deleted on the game server after 30 days at the latest.
